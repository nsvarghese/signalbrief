# Example account briefs

These are snapshots of the Vapi, Retool, and LangChain briefs Nathan generated in the deployed app on October 17, 2026. They are included so reviewers can inspect concrete outputs without signing in.

- [Vapi](vapi.md) — generated brief with the revised opening message Nathan confirmed saving.
- [Retool](retool.md) — generated snapshot, including an unclear criterion and an unsupported seller-experience claim flagged during review.
- [LangChain](langchain.md) — generated snapshot, including an inference about possible onboarding friction that needs validation.

## Provenance and limitations

The exports were prepared from Nathan's shared app text and his confirmation of the Vapi edit, rather than a direct database export. No briefs were regenerated for these files. Navigation, account UI, and duplicate controls were omitted. Company summaries, assessments, unknowns, and source identifiers are preserved as generated; the Vapi opening message is the confirmed revision.

These examples contain model interpretations and potentially inaccurate claims. Publication here does not endorse those claims or establish that a company has a current buying need. Source titles and IDs are included, but the shared text did not include the underlying source URLs or full extracted evidence. For the saved evidence excerpts, use the app's evidence notebook in the owning account.

## Shared inputs

**Seller description — hypothetical demo offering:**

> We help B2B software companies standardize technical customer onboarding with shared implementation plans, integration checklists, and clear handoffs between sales, solutions engineering, and customer success.

**Fit criteria:**

1. Sells software to business customers.
2. Customer onboarding involves technical integrations or infrastructure.
3. Publicly describes implementation or deployment support.

## Review findings

Vapi's deployment support is documented, but the generated brief overstates customer infrastructure responsibilities. Retool's generated draft claims prior seller-client experience that was not supplied in the input. LangChain's implementation complexity does not establish that it experiences onboarding friction. These findings illustrate why the product keeps outreach editable and asks users to inspect the evidence.
